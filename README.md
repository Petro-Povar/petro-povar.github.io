# PETRO.POVAR — сайт шеф-повара Кайржана

- `index.html` — сайт (сеты, меню с корзиной, заявка на праздник)
- `admin.html` — админка: заказы, меню и цены, фото, сеты, тексты, отзывы, Telegram-уведомления
- `content.js` — исходное меню (из PDF шефа); после первого сохранения в админке меню хранится в базе
- `config.js` — адрес сервера (Cloudflare Worker)
- `worker/worker.js` — сервер для Cloudflare Workers, база D1 подключается как `DB`
